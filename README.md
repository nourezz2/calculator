# Python Desktop Calculator

A compact desktop calculator built with Python and Tkinter. This early programming project explores GUI layout, button callbacks, and arithmetic state.

## Features

- Addition, subtraction, multiplication, and division
- Decimal input, sign change, percentage, and square root
- Clear/reset and error handling
- Dark interface with orange operator buttons

## Run locally

Requires Python 3 with Tkinter and a graphical desktop. No third-party Python packages are needed.

```bash
python n.py
```

To check Tkinter availability, run `python -m tkinter`. If unavailable, install your operating system's Python Tk support.

## Files

- [n.py](n.py): interface and calculator logic

## Scope

This is a basic calculator with sequential operations, not an expression parser. It does not implement operator precedence.
